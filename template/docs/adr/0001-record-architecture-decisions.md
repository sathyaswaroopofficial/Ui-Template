# 1. Record architecture decisions

Date: project start · Status: Accepted

## Context

We need to remember why significant technical choices were made, for new team members and AI assistants.

## Decision

We record decisions as short Markdown files in `docs/adr/`, numbered sequentially, using `TEMPLATE.md`.

## Consequences

Decisions are reviewable in PRs and searchable. Superseded ADRs are kept and marked as such.
